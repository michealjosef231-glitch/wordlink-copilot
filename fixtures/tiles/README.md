# Independent token recognition fixtures

These four synthetic tiles use the locally installed Arial regular font at 52 px on a 100×100 light tile, with three dots. Arial regular is not in the training-template font set. They test Qu, O, Q and U at multiple scales, including uncertainty rejection for an ambiguous plain Q. They are generic rendered examples, not crops used to fit recognition templates.

The user reported a real Qu tile being mistaken for O on 2026-10-02. The supplied screenshot contains a path overlay crossing that glyph; its private diagnostic crop remains in ignored artifacts. It must not be represented as an unobscured live recognition accuracy test.
